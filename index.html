ContextByte Automation

A personal automation tool used to publish, manage and analyse content for the ContextByte YouTube channel.

What this application does

ContextByte Automation connects to the authorised channel owner's YouTube account through Google OAuth. It is used only to support the ContextByte publishing workflow.

  • Upload approved ContextByte videos to YouTube.
  • Read channel and video metadata needed to manage published content.
  • Read YouTube Analytics data to evaluate content performance.

The application is for the channel owner's personal use. It is not offered as a public software service and does not sell or share Google user data.

Google data access

The application requests only the YouTube permissions required for its publishing and analytics functions. Access can be revoked at any time from the Google Account security settings.

For details about how data is handled, read the Privacy Policy.
